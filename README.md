# Compagnon

Compteur de vies Magic en français, conçu pour un appareil au centre de la table.

## Développement

```sh
pnpm install
pnpm dev
```

## Vérification

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

Application Next.js exportée en site statique dans `out/`. Aucun compte ni backend.
